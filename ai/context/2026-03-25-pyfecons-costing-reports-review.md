# PyFECONS Costing Reports Review

Review of all 8 CATF costing report variants generated by PyFECONS, for use as context in future development work.

Commands to generate:

```bash
python3 RunCostingForCustomer.py mfe CATF --lite

python3 RunCostingForCustomer.py ife CATF --lite
python3 RunCostingForCustomer.py ife CATF --safety --lite
```

## Pipeline: How Reports Are Generated

1. **Inputs** — `DefineInputs.py` (or `DefineInputsSafety.py`) returns an `AllInputs` object. Written to `inputs.json` / `inputs_safety.json`.
2. **Costing** — `RunCosting(inputs)` computes all cost categories. Written to `data.json` / `data_safety.json`.
3. **Report Content** — `CreateReportContent()` (full) or `CreateReportContentLite()` hydrates LaTeX templates with computed values. Section metadata written to `sections.json` / `sections_safety.json` / `sections_lite.json` / `sections_safety_lite.json`.
4. **Rendering** — `RenderFinalReport()` compiles LaTeX to PDF. Final `.tex` and `.pdf` written to output dir.

The report filename is determined by `get_report_filename()` in `RunCostingForCustomer.py`:
- `{mfe|ife}-report.{tex|pdf}` (base)
- `{mfe|ife}-report-safety.{tex|pdf}` (safety)
- `{mfe|ife}-report-lite.{tex|pdf}` (lite)
- `{mfe|ife}-report-safety-lite.{tex|pdf}` (safety + lite)

## Report Structure

### Full Report (39 sections for MFE, same count for IFE)

The full `.tex` is a LaTeX document that `\input{}`s section files from `Modified/` (hydrated templates) and `Originals/` (static text):

1. Cover page, foreword, table of contents
2. Methodology (`Originals/method.tex`)
3. Power balance description (`Originals/powerBalanceMFEDT.tex` / `powerBalanceIFEDT.tex`)
4. **Power Accounting Table** — computed power flow from fusion power to net electric
5. **CAS 10** — Pre-construction costs (site, licensing, permits)
6. **CAS 20** — Capitalized Direct Costs (intro)
7. **CAS 21** — Structures and Site Facilities (17 sub-accounts)
8. **CAS 22** — Reactor Plant Equipment (the largest cost bucket):
   - 22.01 — Reactor Equipment overview
   - 22.01.01 — First Wall & Blanket
   - 22.01.02 — High Temperature Shield
   - 22.01.03 — Magnets (MFE: tokamak variant) / Lasers (IFE)
   - 22.01.04 — Supplemental Heating
   - 22.01.05 — Primary Structure
   - 22.01.06 — Vacuum System
   - 22.01.07 — Power Supplies
   - 22.01.08 — Divertor (MFE) / Target (IFE)
   - 22.01.09 — Direct Energy Conversion
   - 22.01.11 — Assembly and Installation
   - 22.01.19 — Scheduled Component Replacement
   - **22.01.20 — Disruption Mitigation** (safety only, MFE only)
   - 22.02 — Main Heat Transfer
   - 22.03 — Auxiliary Cooling
   - 22.04 — Radioactive Waste Treatment
   - 22.05 — Fuel Processing & Storage
   - 22.06 — Other Plant Equipment
   - **22.06.06 — Remote Handling** (safety only, MFE only)
   - 22.07 — Instrumentation and Control
9. **CAS 23** — Turbine Plant Equipment
10. **CAS 24** — Electric Plant Equipment
11. **CAS 25** — Miscellaneous Plant Equipment
12. **CAS 26** — Heat Rejection
13. **CAS 27** — Special Materials
14. **CAS 28** — Digital Twin
15. **CAS 29** — Contingency
16. **CAS 30** — Capitalized Indirect Service Costs
17. **CAS 40** — Capitalized Owner's Cost
18. **CAS 50** — Capitalized Supplementary Costs
19. **CAS 60** — Capitalized Financial Costs
20. **Cost Accounting Structure** — Summary table with all CAS items + pie charts
21. **LCOE** — Levelized Cost of Electricity (includes CAS 70, 80, 90)
    - CAS 70 — O&M costs
    - CAS 80 — Fuel costs
    - CAS 90 — Annualized Financial Costs (capital recovery factor)
22. NPV section (commented out in final report — `%\input{Modified/NPV.tex}`)
23. Appendix: Safety appendix (safety reports only), Glossary, Bibliography

### Lite Report (3 data sections)

Dramatically simplified — only:
1. Cover page, methodology summary, safety summary
2. Power Accounting Table
3. Cost Accounting Structure (summary table + pie charts)
4. LCOE
5. Bibliography

No individual CAS section breakdowns, no foreword, no table of contents.

## Safety Mode: What Changes

Safety mode is toggled by `--safety` flag and `DefineInputsSafety.py`.

### Input Changes
- `include_safety_hazards_costs = True`
- `region = Region.US` (drives region-dependent licensing costs)
- `TritiumRelease` inputs added: HTO inventory (4700g), dust tritium inventory (689 kg/yr), stack height (20m)

### Extra Cost Categories (MFE only)
- **CAS 22.01.20 — Disruption Mitigation System**: $13.2M (shattered pellet injection, based on ITER cost basis)
- **CAS 22.06.06 — Remote Handling System**: $55.0M (based on ITER divertor remote handling contract)

### Modified Cost Categories
- **CAS 10**: Pre-construction increases from $250.62M to $307.75M (MFE). Extra $3.6M in safety licensing (C110200) and $53.5M increase in construction cost (C130000)
- **CAS 70 (O&M)**: Small increase for insurance add-on under CAS 78 ($0.21M/yr)
- **CAS 78**: Insurance add-on — annual third-party liability insurance based on fission baseline scaled by fusion risk profile

### LaTeX Conditional
Safety sections are wrapped in `\ifsafetycosts ... \fi`. The document preamble sets `\safetycoststrue` or `\safetycostsfalse`. This means the same template can handle both — safety sections are present but conditionally rendered.

### IFE Safety Note
IFE safety adds only licensing costs (CAS 10) and insurance (CAS 78). No disruption mitigation (not applicable to IFE) and no remote handling extra cost was added in the current implementation.

## MFE vs IFE: Key Differences

### Same section structure
Both have identical section keys (39 sections). The differences are in the template file names and computed values.

### Template name differences
| Section | MFE Template | IFE Template |
|---------|-------------|-------------|
| PowerTable | `powerTableMFEDT.tex` | `powerTableIFEDT.tex` |
| CAS 22.01.01 | `CAS220101_MFE_DT.tex` | `CAS220101_IFE_DT.tex` |
| CAS 22.01.03 | `CAS220103_MFE_DT_tokamak.tex` | `CAS220103_IFE_DT.tex` |
| CAS 22.01.04 | `CAS220104_MFE_DT.tex` | `CAS220104_IFE_DT.tex` |
| CAS 22.01.06 | `CAS220106_MFE.tex` | `CAS220106_IFE.tex` |
| CAS 22.01.07 | `CAS220107_MFE.tex` | `CAS220107_IFE.tex` |
| CAS 22.01.08 | `CAS220108_MFE.tex` | `CAS220108_IFE.tex` |

### Key cost/performance differences
| Metric | MFE | IFE |
|--------|-----|-----|
| Fusion Power | 2,600 MW | 2,500 MW |
| Net Electric Power | 1,317 MW | 1,025 MW |
| Engineering Q | 6.74 | 8.45 |
| Scientific Q | 52.0 | 247.5 |
| CAS 22 Reactor Equip | $22,453M | $4,862M |
| Total Capital Cost | $29,690M | $9,152M |
| LCOE | 289.1 $/MWh | 121.9 $/MWh |
| Annual Fuel Cost | $0.18M | $16.44M |

MFE is ~3x more expensive in capital and LCOE. The dominant cost driver is CAS 22.01.01 (First Wall & Blanket) at $9,777M for MFE vs much less for IFE.

### Input differences
- MFE: Spherical tokamak, DT fuel, has TF/CS/PF magnets (10 coils), `ConfinementType.SPHERICAL_TOKAMAK`
- IFE: Laser-driven direct drive, PB11 fuel, has laser inputs instead of coils, `ConfinementType.LASER_DRIVEN_DIRECT_DRIVE`
- IFE uses `TargetFactory` and `Lasers` input classes not present in MFE
- MFE uses `Coils` with detailed `Magnet` definitions not present in IFE

## Template Hydration System

Each section has a LaTeX template with placeholder tokens (e.g., `C100000`, `PNRL`, `ETATH`). The `sections.json` records the mapping from token to computed value. For example:

```json
"CAS10Section": {
    "template_file": "CAS100000.tex",
    "replacements": {
        "Nmod": "1",
        "C100000": "250.62",
        "C110100": "17.62",
        ...
    }
}
```

Templates live in the `pyfecons/report/` directory in the library. Some sections are "Originals" (static explanatory text, not hydrated) and some are "Modified" (hydrated with computed values).
